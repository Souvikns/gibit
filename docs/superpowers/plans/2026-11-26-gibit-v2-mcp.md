# Gibit v2 MCP Implementation Plan (Plan 2 of 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give Claude Code read/write access to gibit (never GitHub) over a bearer-authenticated MCP endpoint, backed by a shared triage service the dashboard will reuse in Plan 3, plus a shipped `triage` prompt.

**Architecture:** `lib/triage/` is the single service layer: pure helpers (refs, needs-reply, briefing selection) plus DB functions (list/get items, move, notes, drafts, reports, briefing). `app/api/mcp/route.ts` mounts `mcp-handler` v2, wraps it in `withMcpAuth` with a constant-time `GIBIT_SECRET` check, and registers thin tools that call the service with `actor: "claude"`. The `triage` prompt encodes the spec's playbook.

**Tech Stack:** `mcp-handler@^2.4` + `@modelcontextprotocol/server@^2.4` (Standard Schema tools), `zod@^4`, Drizzle/Neon from Plan 1.

**Spec:** `docs/superpowers/specs/2026-11-26-gibit-v2-triage-design.md` (sections "MCP server", "Board columns", "Data model › Overlay").

**Depends on:** Plan 1 (`docs/superpowers/plans/2026-11-26-gibit-v2-foundation.md`) — `db()`, schema, `syncStep`, `getOwnerLogin`, `safeEqual`, `requireSession`.

## Global Constraints

- All Plan 1 global constraints apply (Bun, tokens-only styling, strict TS, read-only GitHub).
- Endpoint: `/api/mcp` (mcp-handler v2 mounts at the route path; no `[transport]` segment). Auth: `Authorization: Bearer <GIBIT_SECRET>`, required; compare with `safeEqual`.
- Item refs are `owner/repo#number` (case-insensitive owner/repo match).
- MCP writes use `actor: "claude"`; dashboard writes (Plan 3) use `actor: "admin"`. Every overlay write appends to `activity_log`.
- Claude cannot add/remove repos and cannot set `seen_at`.
- Tool results are JSON text (`content: [{ type: "text", text }]`); failures return `isError: true` with a readable message.
- `get_briefing` default `since` = `app_state.last_briefing_at`, else 24 h ago; it then stores `now`. Lists capped at 25 entries each with full counts.
- `route.ts` exports `maxDuration = 60` so `sync` fits its 45 s budget.

### Task 1: Pure triage helpers

**Files:** Create `lib/triage/types.ts`, `lib/triage/refs.ts`, `lib/triage/refs.test.ts`, `lib/triage/signals.ts`, `lib/triage/signals.test.ts`, `lib/triage/briefing.ts`, `lib/triage/briefing.test.ts`

**Interfaces (produces):**
```ts
// types.ts
export interface ItemSummary {
  ref: string; repo: string; number: number; kind: ItemKind; title: string; state: ItemState;
  author: string; authorRole: string; column: BoardColumn; priority: Priority | null; lastReason: string | null;
  createdAt: string; updatedAt: string; lastCommentBy: string | null; lastCommentAt: string | null;
  lastCommentIsMaintainer: boolean; isDraft: boolean; reviewDecision: string | null;
  requestedReviewers: string[]; labels: string[]; htmlUrl: string; hasDraft: boolean;
  unansweredOwnerMention: boolean; unansweredMaintainerMention: boolean;
}
export interface ColumnChange { ref: string; title: string; from: string | null; to: string; reason: string | null; actor: Actor; at: string }
export interface BriefingSection { total: number; items: ItemSummary[] }
export interface Briefing {
  since: string; owner: string; lastSyncAt: string | null; columnCounts: Partial<Record<BoardColumn, number>>;
  newItems: BriefingSection; needsReply: BriefingSection; reviewRequested: BriefingSection;
  unansweredMentions: BriefingSection; approvedNotMerged: BriefingSection; columnChanges: ColumnChange[];
}
export interface ListFilters {
  repo?: string; kind?: ItemKind; column?: BoardColumn; priority?: Priority;
  needsReply?: boolean; mentionsMe?: boolean; reviewRequested?: boolean; limit?: number;
}
// refs.ts
parseRef(ref: string): { owner: string; name: string; number: number } | null
formatRef(owner: string, name: string, number: number): string
// signals.ts
lastSpeakerIsTeam(s: ItemSummary, owner: string): boolean
needsReply(s: ItemSummary, owner: string): boolean      // open && last speaker not team
isReviewRequested(s: ItemSummary, owner: string): boolean // open PR, owner in requestedReviewers (case-insensitive)
// briefing.ts
selectBriefing(input: { items: ItemSummary[]; changes: ColumnChange[]; since: Date; owner: string; lastSyncAt: string | null }): Briefing
```

**Behavior:**
- `parseRef` accepts `owner/repo#12`, trims, validates with `isValidLogin`/`isValidRepoName`, number ≥ 1.
- `selectBriefing`: `newItems` = createdAt > since; `needsReply` = `needsReply()` && updatedAt > since; `reviewRequested` = all `isReviewRequested`; `unansweredMentions` = open && (owner or maintainer mention unanswered); `approvedNotMerged` = open PR with `reviewDecision === "APPROVED"`; each sorted updatedAt desc, capped at 25 with `total`; `columnCounts` over all items; `columnChanges` passed through (newest first).

### Task 2: Triage service (DB)

**Files:** Create `lib/triage/service.ts`; dev smoke script run from `scripts/` (not committed).

**Interfaces (produces):**
```ts
export class TriageError extends Error {}
listRepoSummaries(): Promise<{ repo: string; cloneUrl: string; defaultBranch: string; enabled: boolean; lastSyncedAt: string | null; lastError: string | null }[]>
listItems(filters: ListFilters): Promise<{ total: number; items: ItemSummary[] }>   // default limit 50, max 200, updatedAt desc
getItem(ref: string): Promise<ItemDetail>    // summary + body + thread (asc) + notes + current draft + last 50 activity
moveItem(input: { ref; column: BoardColumn; reason: string; priority?: Priority | null; actor: Actor }): Promise<ItemSummary>
addNote(input: { ref; body; kind: "research" | "note"; author: "claude" | "admin" }): Promise<{ id: number }>
saveDraft(input: { ref; body; author: "claude" | "admin" }): Promise<{ id: number }>   // replaces the item's current "draft"
saveReport(input: { title; body }): Promise<{ id: number; createdAt: string }>
listReports(limit?: number): Promise<{ id; title; body; createdAt }[]>
getBriefing(since?: string): Promise<Briefing>  // stores last_briefing_at = now
```
`ItemDetail = ItemSummary & { body: string; thread: { author; authorRole; kind; reviewState; body; createdAt }[]; notes: { id; author; kind; body; createdAt }[]; draft: { id; body; status; updatedAt } | null; activity: { actor; action; detail; createdAt }[] }`.

**Behavior:** unknown ref → `TriageError("Unknown item owner/repo#N — run sync or check the ref")`; invalid ref → `TriageError("Invalid ref …, expected owner/repo#number")`. Every write appends `activity_log` with the actor. `listItems` applies SQL filters for repo/kind/column/priority and JS filters for needsReply/mentionsMe/reviewRequested.

```ts
export const maxDuration = 60;
export { authed as GET, authed as POST, authed as DELETE };
```
