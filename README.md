# gibit

Next.js 16 + Tailwind CSS v4 application. Design tokens are mapped from
[`design.md`](./design.md) into Tailwind's `@theme` in
[`app/globals.css`](./app/globals.css).

## Getting started

Install dependencies:

```bash
bun install
```

Run the dev server:

```bash
bun run dev
```

Build for production:

```bash
bun run build
```
